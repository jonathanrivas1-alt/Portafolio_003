# /public — Static assets

Coloca aquí los siguientes archivos:

- **profile.jpg** — Tu foto del hero (la misma que subiste en el chat).
  Recomendado: 1200×1200 px, JPG optimizado.
- **CV_Jonathan_Rivas.pdf** — Tu CV (fallback si no se sube por admin).
- **favicon.ico**, **og-image.png** — opcional.

Cuando Supabase esté configurado, los assets dinámicos se sirven desde
Storage automáticamente y estos archivos sirven solo como fallback local.
